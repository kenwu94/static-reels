# assets

- `fonts/`: drop a `.ttf` or `.otf` here and it is used for all on-screen text
  (the first one alphabetically wins). Leave it empty to use a system monospace
  font (Consolas on Windows, Menlo on macOS, DejaVu Sans Mono on Linux).
  You can also point `STATICREELS_FONT` in `.env`, or `"font"` in the story JSON,
  at a specific file.
