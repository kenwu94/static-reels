# static-reels

Turns a story JSON file (plus optional AI-generated clips) into a finished
vertical horror Reel for **@static.in.the.walls**: 1080x1920, 30 fps, H.264 +
AAC, yuv420p, `+faststart`.

Everything that isn't AI footage is generated by code, so it costs nothing:
TV static, glitchy typewriter text, the countdown, the end card, the
REC/timestamp overlay, and all the sound design (drone, hiss, heartbeat,
knocks). No network calls are made except `pip install`.

## Setup

You need **Python 3.11+** and **ffmpeg** (which includes `ffprobe`).

1. Check for ffmpeg with `ffmpeg -version`. If it's missing:
   - **Windows:** `winget install --id Gyan.FFmpeg -e`, then open a **new** terminal.
     Or download a "release essentials" zip from <https://www.gyan.dev/ffmpeg/builds/>,
     unzip it to e.g. `C:\ffmpeg`, and add `C:\ffmpeg\bin` to your PATH.
   - **macOS:** `brew install ffmpeg`
   - **Linux:** `sudo apt install ffmpeg` (Debian/Ubuntu), `sudo dnf install ffmpeg` (Fedora), `sudo pacman -S ffmpeg` (Arch)
2. Create a virtual environment and install. Run these from the project folder:

   ```powershell
   # Windows (PowerShell)
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

   ```bash
   # macOS / Linux
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

   `requirements.txt` installs numpy, Pillow and python-dotenv, plus this
   project in editable mode, which gives you the `staticreels` command.
3. Optional: `copy .env.example .env` (or `cp`) and set a font or ffmpeg path.
   API keys will go in `.env` too, but nothing uses one yet. Never commit `.env`.
4. Run the tests: `python -m unittest discover -s tests -v`

Always run `staticreels` from the project folder. It finds `clips/`,
`output/`, `assets/` and `.env` relative to the current directory.

## The 5-step workflow

```text
1. staticreels prompts stories/static_in_the_walls.json
2. (generate the clips in your AI video tool, save them into clips/)
3. staticreels render  stories/static_in_the_walls.json
4. staticreels check   output/static_in_the_walls.mp4
5. staticreels publish output/static_in_the_walls.mp4 --caption-file output/static_in_the_walls.caption.txt
```

1. **Prompts.** This prints each AI clip's prompt, the aspect ratio and length it needs, and
   the exact filename to save it as (`clips/clip1.mp4`, ...). It also tells you which clips are
   still missing.
2. **Generate.** Paste each prompt into your AI video tool, export it as 9:16, and save it under
   the printed name. Any resolution, aspect ratio or frame rate works. Clips are scaled and cropped
   to fill 1080x1920. Longer clips are trimmed, and clips that are too short hold their last frame.
   Every clip then gets film grain, a slight desaturation, a contrast boost and the REC overlay.
3. **Render.** This builds `output/<story>.mp4` and `output/<story>.caption.txt`, a caption template
   that is never overwritten once you've edited it.
   - `--placeholders` renders with dark, grainy code-made stand-in clips, labelled "PLACEHOLDER".
     That runs the whole pipeline with no AI footage, which is handy for timing and sound checks.
     These renders can't be published.
   - `--procedural` uses the same code-made scenes as the **final footage**: no label, full length,
     and no AI clips needed. The caption notes then say there's no AI footage.
   - `--parts` also writes each segment as its own MP4 in `output/<story>_parts/`
     (`01_static_text.mp4` … `07_end_card.mp4`), cut frame-accurately from the finished video.
4. **Check.** This runs ffprobe and reports OK or FAIL for resolution, frame rate, codecs, pixel
   format, faststart and duration. It also prints the file size and measures loudness (the target
   is -14 LUFS). Add `--raw` for ffprobe's full JSON. To see the visuals at a glance:
   `staticreels sheet output/static_in_the_walls.mp4` writes a 6-frame contact sheet PNG.
5. **Publish.** This is a dry run by default. It prints the caption, the hashtag count, the
   schedule and the notes from your caption file, then stops. With `--yes` it shows all of that
   again and asks you to type `publish`. Even then, the only backend is **manual**: it prints the
   steps for uploading in the Instagram app (Professional account) or Meta Business Suite. It never
   calls Instagram's API. Optional: `--schedule "2026-10-31 21:00"` (local time).
   Publishing is refused when the video was rendered with `--placeholders` or fails `check`.

**AI labels:** the caption template includes a reminder. Before posting, check Instagram's
current AI-labelling rules and turn on the AI label where it's required, for example when a clip
shows realistic AI-generated people.

## Story format

See `stories/static_in_the_walls.json`. Segment start times are not stored. Each segment starts
when the previous one ends, so changing one duration can't leave a gap. Times inside a segment
(`lines[].start`, `handle_start`) are relative to that segment. `audio_cues` times are absolute.

| Field | Notes |
|---|---|
| `title`, `fps`, `size` (`"1080x1920"`), `duration` | `duration` is optional. If present, it must equal the sum of the segment durations. |
| `voiceover` | Optional path to an audio file. The bed is ducked under it, then everything is loudness-normalized. |
| `font` | Optional font file. Overrides `.env` and `assets/fonts/`. |
| `caption.hook`, `caption.hashtags` | Used for the caption template. |
| `segments[].type` | `static_text`, `ai_clip`, `countdown`, `end_card`, `spectrogram`, `blueprint` |
| `segments[].duration`, `fade_in`, `fade_out`, `glitch` (0-1) | `glitch` is how often the text glitches. |
| `static_text`: `background` | `static` (default), `dark` (near-black noise) or `black` |
| `segments[].lines[]` | `{text, start, end?, cps?}`, typed out at `cps` characters per second (default 28). Validation fails if a line can't finish typing before it disappears. |
| `ai_clip`: `clip`, `prompt`, `overlay {rec_dot, timestamp}`, `cut_to_black` | `cut_to_black` is the number of seconds of hard black at the end of the clip. |
| `countdown`: `digits` | Numbers or short text, e.g. `[5,4,3,2,1]` or `["2'6\"", "1'8\""]`, spread evenly over the segment. Wide text is shrunk to fit. |
| `end_card`: `handle`, `handle_start` | |
| `spectrogram`: `plan`, `reveal` | A spectrogram scrolls in over `reveal` seconds, and its noise resolves into a floor plan. |
| `blueprint`: `plan`, `pencil`, `pencil_start` | The same floor plan drawn in ink on aged 1926 paper, with an optional handwritten pencil note. |
| `plan` | `{bedroom: 0-1, label: "11'4\"", outline: null / "bed" / "wall"}`. `bedroom` 1 is the full room and 0 means the wall has swallowed it (a studio). |

**Audio cues.** Every cue takes `gain` and `pan` (-1 is left, 1 is right). Range cues also take
`gain_to`, which ramps the gain from `gain` to `gain_to` across the range.

| Kind | Cues |
|---|---|
| Range `{start, end}` | `drone`, `hiss`, `grind` (plaster), `breathing` (`period` = seconds per breath), `panic` (fast, shaky breathing), `paper` (wallpaper crinkle), `tick` (clock), `riser` (endlessly rising pitch), `drawtones` (spectrogram lines), `day` (traffic) |
| Point `{times: [...]}` | `heartbeat`, `knock`, `creak`, `bedsprings`, `tape` (tape measure pull + snap), `snap`, `beep`, `sub` (deep hit), `thud`, `sample` (`file`: any recorded sound, e.g. your own breathing) |
| Whole-mix shaping | `room` `{size 0-1}` adds room tone and an echo whose length follows `size`. `muffle` `{cutoff}` low-passes everything, as if heard through a wall. `silence` gives dead silence. |

Wear headphones when you check a mix: `pan` is what puts the wall on the listener's left.

**The Floor Plan** (`stories/floor_plan_part1-4.json`) is a 4-part series built from these cues.
The bedroom's echo shrinks from part to part (`room` size 0.6, then 0.4, then 0.05, then 0), so the
room gets smaller in your ears as well as on the plans.

On-screen text stays in the middle of the frame, clear of the Reels UI at the bottom and the
right edge.

## Project layout

```text
src/staticreels/
  cli.py        command-line interface
  story.py      JSON loading, validation, timeline math
  visuals.py    static, typewriter + glitch text, countdown, end card, clip treatment, REC overlay,
                spectrogram and blueprint segments
  plans.py      the floor-plan line drawing used by spectrogram/blueprint
  audio.py      numpy synthesis of every sound cue, stereo panning, room echo, muffling,
                voiceover ducking, loudnorm
  assemble.py   streams all frames into one ffmpeg encode; `check` and contact sheet
  publish.py    caption template, dry-run-first publishing, manual backend
  ff.py         small ffmpeg/ffprobe subprocess helpers
  providers/    base.py (interface), manual.py (default), placeholder.py (--placeholders)
```

**Adding an AI provider or a scheduler.** Kling, Dreamina, Google Flow, Ayrshare, Metricool and
the like are deliberately not implemented. Add one only after reading that service's current
official API docs. Subclass `providers/base.Provider` (or add a backend to `publish.BACKENDS`) and
read its key from `.env`.

## Troubleshooting

**`ffmpeg was not found on PATH`**
Install it as described above, then open a *new* terminal (PATH is only re-read by new
terminals). If you'd rather not touch PATH, set `STATICREELS_FFMPEG` and `STATICREELS_FFPROBE`
in `.env` to the full `.exe` paths.

**`python` is not recognized (Windows)**
Microsoft Store Python lives in `%LOCALAPPDATA%\Microsoft\WindowsApps`. Add that folder to PATH,
or create the venv with the full path to `python.exe`. Once the venv is activated, `python`
works either way.

**Font errors / wrong-looking text**
By default the first `.ttf`/`.otf` in `assets/fonts/` is used, then a system monospace font
(Consolas / Lucida Console / Courier New on Windows, Menlo on macOS, DejaVu Sans Mono on Linux).
If none is found, install one (e.g. `sudo apt install fonts-dejavu-core`) or point
`STATICREELS_FONT` in `.env` at a font file. A font you name explicitly that doesn't exist is an
error, never a silent fallback.

**`missing AI clip(s)`**
Run `staticreels prompts <story>` to see the exact filenames, or render with `--placeholders`.

**Story errors**
Validation messages name the exact field, e.g. `segments[0].lines[1]: typing takes until 3.10s`.
Start the line earlier, shorten it, or raise its `cps`.

**Large files**
Full-frame static barely compresses. The encoder caps the bitrate at about 14 Mbit/s, so a
30-second Reel comes out around 30-50 MB. Instagram re-encodes on upload anyway.
